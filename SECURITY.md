# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in OpenVideo Downloader, please report it responsibly:

- Do **not** open a public issue on GitHub.
- Submit a private report via GitHub Security Advisories or contact the project maintainers directly.
- Include detailed steps to reproduce the issue.
- Maintainers will review and respond promptly.

## Security Practices

- **Zero DRM Circumvention:** This application strictly does not bypass Digital Rights Management (DRM) or access controls.
- **Process Isolation:** Download engines are executed with separated arguments without shell evaluation.
- **Data Protection:** No user data or telemetry is transmitted externally.
